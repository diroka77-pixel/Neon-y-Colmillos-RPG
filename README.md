# Neón y Colmillos — Godot v0.1.0

Prototipo técnico de RPG cyberpunk pixel art 2.5D para Android. Incluye un mapa procedural determinista, marcador temporal controlable, cámara y controles táctiles.

No incluye todavía los sprites canónicos de Diroka, Sora y Vane. El arte provisional no representa a esos personajes.

## Ejecutar
Abrir project.godot en Godot 4.3 y ejecutar la escena principal.

## Android
El workflow de GitHub Actions intenta exportar una APK de depuración. **Pendiente de validar mediante ejecución real.** La clave de firma se genera en cada compilación y no sirve para actualizaciones persistentes.

## Canon
Conservar intactos los diseños y el lore aprobados de Neón y Colmillos. No introducir imágenes recortadas defectuosas.
